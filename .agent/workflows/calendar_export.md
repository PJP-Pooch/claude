---
description: How to use the Calendar View Export feature
---

1.  Navigate to the Seasonality Explorer tool.
2.  Perform a seasonality analysis.
3.  Switch to the "Calendar" view using the toggle button above the results.
4.  Click the "Export Calendar" button located at the top right of the calendar view.
5.  A CSV file named `seasonality_calendar.csv` will be downloaded.
6.  This file contains a list of tasks with start dates, descriptions, and priorities, suitable for importing into calendar applications or project management tools.
