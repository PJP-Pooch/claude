---
description: How to use the Target Domain Ranking Check feature
---

1.  Navigate to the Seasonality Explorer tool.
2.  Enter your keywords in the input area.
3.  Check the "Enable SERP Enrichment" checkbox.
4.  A new input field "Target Domain (Optional)" will appear.
5.  Enter your domain (e.g., `example.com`).
6.  Click "Get Seasonal Search Volumes".
7.  The dashboard will display a "Current Rank" column showing your ranking position and URL for each keyword where you rank in the top 100 (or top 3 depending on API depth).
